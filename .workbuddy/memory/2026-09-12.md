### 踩到的 PY32 与 STM32 差异（写寄存器前必须核对，别照搬 ST）

- UART（RM 38）**没有 UE/TE/RE 使能位**，写 `BRR != 0` 即工作；波特率 4 位小数在独立寄存器 `BRRF`；
  `CR1.PS = 1` 是**偶**校验（与 ST 的 USART 相反）。
- 初始化顺序必须照 `LL_UART_Init`：先 `CR1`/`CR3` 再 `BRR`/`BRRF`，否则 `SR.BUSY_ERR`。
  `CR2` 复位值 0x8（BUSYERRIE=1），同步驱动显式写 0。
- 时钟位：UART1/2/3 → `APB1ENR1` bit19/20/23（分频用 PCLK1）；USART1 → `APB2ENR`；USART2/3 → `APB1ENR1`
  bit17/18；LPUART → `APB1ENR2` bit1。
- 引脚 AF：UART1 = PC10/PC11(AF5)、UART2 = PC12/PD2(AF5)、UART3 = PA2/PA1(**AF14**)（DS 端口复用表）。
- PAC 的寄存器字段定义在 `py32e407-pac/src/<periph>/<reg>.rs`，只 grep `src/<periph>.rs` 会误判没有字段。

### LPUART 与第 38 章 UART 的关键差异（已验证，勿互抄）

- 有 `CR1.UE` 使能位，且必须在 `UE=0` 时配 `CR1/CR2/PRESC`；HAL 序列是
  `UE=0 → 配置 → UE=1 → 等 ISR.TEACK/REACK`。
- `CR1.PS`：LPUART 是 `0=偶/1=奇`（同 STM32），**与第 38 章 UART 的 `PS=1=偶` 相反**。
- 波特率：`LPUARTDIV = (fck_pres*256 + baud/2)/baud`，`fck_pres = 时钟/PRESC`；
  `PRESC` 分频表 `[1,2,4,6,8,10,12,16,32,64,128,256]` 非 2 的幂；`BRR` 合法 0x300..=0xFFFFF
  （PAC 字段名 `bbr`）；另需 `3*baud <= fck_pres <= 4096*baud`。
- `CR2.STOP`：`00`=1 位、`10`=2 位，`01/11` 保留；`CR2.TXOE_ALWAYS_ON` 复位值为 1，
  只能用 `modify` 改 STOP/MSBFIRST/SWAP 以免被清掉。
- `ISR.TC` 只读，只能经 `ICR.TCCF` 写 1 清零 —— 发完一串数据要先清 TC 再等它置位。
- 时钟源由 `RCC_CCIPR.LPUART1SEL[1:0]`（bits12:13）决定：00=PCLK1、01=SYSCLK、10=HSI、11=LSE；
  驱动里读该字段换算（LSE 档返回 `InvalidConfig`，因为 crate 的 rcc 未实现 LSE）。
- 引脚（DS 复用表 + 官方例程核对）：TX = PA2@AF12 / PB11@AF8 / PC1@AF8；
  RX = PA3@AF12 / PB10@AF8 / PC0@AF8。未实现 CTS/RTS/DE 与 9 位字长。
