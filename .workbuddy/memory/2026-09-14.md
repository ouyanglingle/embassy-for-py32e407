## demo-py32 移植参考设计 ST7735 LCD 驱动并接线点亮（SPI3）

- 需求：把 `参考设计\stm32f412rgt6-microboard\src\lcd\`（ST7735 TFT，embedded-hal 1.0 泛型）移植到
  demo-py32，接线 SCK=PB3 / MOSI=PB5 / DC=PD1 / RST=PD0，CS 接地、BLK 接 3V3。
- 关键判断（先暂停确认后执行）：参考驱动泛型于 `embedded-hal` 的 `SpiBus/OutputPin/DelayNs`，
  而 embassy-py32 是自定义同步 API，**不能直接拷贝**。用户选定「路线 A：加兼容层 + 假 MISO 用 PB4」。
- 落地改动：
  - `demo-py32/Cargo.toml`：加 `embedded-hal = "1.0"`；`cortex-m` 加 `inline-asm`（供 `asm::delay`）。
  - 复制 `参考设计\...\src\lcd\{mod,st7735,color,display,font,font7x10,utils}.rs` → `demo-py32/src/lcd/`（原样，便于日后同步）。
  - 新建 `demo-py32/src/lcd_hal.rs`：`SpiBusAdapter` / `OutputPinAdapter` / `Delay` 三个适配器；
    SPI 错误用本地 newtype `SpiErrorAdapter` 绕开孤儿规则（`embedded_hal::spi::Error` 不能直接 impl 到 embassy 的错误类型）。
  - `main.rs`：`#[allow(dead_code)] mod lcd; mod lcd_hal;` + SPI3(PB3/PB5/PB4 假 MISO, 10MHz, MODE_0) 接线，
    `St7735Driver::new(spi, None, dc, Some(rst), None, delay, cfg)`，160×80 横屏（x_off26/y_off1）；
    init 后填色 + 写字，主循环每秒整屏换色重绘（验证"亮着且在刷新"）。
- 验证：`cargo build --target thumbv7em-none-eabihf`（dev 与 release）均 **0 error 0 warning**；release ELF 628 KB。
- 待用户实测：真正点亮需烧录后看屏；ST7735 的 x/y offset 要按实际屏型微调；PB4 是 NJTRST，
  若影响烧录改成 `p.PC11`（一行）。SPI 频率 10MHz 偏稳，可上调。
- 注意点：embassy-py32 的 SPI 是全双工、构造强制要 MISO 脚（无 tx-only 版本），故只写屏需借假 MISO。
