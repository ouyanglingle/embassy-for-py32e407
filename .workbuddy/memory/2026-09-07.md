## 实现 GPIO 同步驱动（embassy-py32）
- 按 py32e407-sync-driver Skill 流程完成：调研 HAL C（py32e407_hal_gpio.c 的 HAL_GPIO_Init）→ LL（ll_bus.h/ll_gpio.h）→ RM 第 9 章 → PAC 交叉验证。
- 新增文件：embassy-py32/src/{gpio.rs, peripherals.rs}；重写 embassy-py32/src/lib.rs（#![no_std]、Peri、PeripheralType、pac re-export）；embassy-py32/Cargo.toml 增加 py32e407-pac path 依赖。
- API 面：Flex（任意模式切换）+ Input/Output/OutputOpenDrain 包装 + Pull/Speed/Level/OutputType 枚举；引脚类型 PA0…PF15 由宏生成，经 Pin trait（PORT/PIN 常量）携带元信息。
- 关键 PY32 事实（代码注释中均已标注出处）：
  - 时钟使能 RCC_AHB2ENR.IOPxEN，LL 宏置位后必须读回一次 RCC（"Delay after an RCC peripheral clock enabling"），驱动已复刻；不做端口复位（会清同端口其他引脚配置）。
  - SVD/PAC 拼写差异：速度寄存器 OSPDDER（RM 写 OSPEEDR）、PUPDR 字段 pupdN、OSPEEDR 字段 ospeedN、IDR 字段 idN、ODR 字段 odN、AF 字段 afselN（AFRL 0-7 / AFRH 8-15）。
  - svd2rust 0.37 的 W 无 bits() 读取器，RMW 必须 modify(|r, w|) 用 r.bits() 读当前值。
  - HAL_GPIO_Init 顺序：AFR→MODER→OSPEEDR→OTYPER→PUPDR；驱动改为附属寄存器先行、MODER 最后切（防毛刺）。
- demo-py32/src/main.rs 改为用驱动点灯（PA5，Output::new + BSRR 原子翻转），启动正确性：默认 HSI16、cortex-m-rt link.x/memory.x 不变。
- 编译验证：cargo build（dev + release，thumbv7em-none-eabihf）零 error 零 warning。

## 实现 RCC 同步驱动（embassy-py32）
- 新增 embassy-py32/src/rcc.rs，lib.rs 挂 pub mod rcc；demo-py32/src/main.rs 演示 HSI16 → PLL(HSI/2×10)=80MHz 升频 + PA5 点灯（SysTick 用返回的 Clocks.hclk）。
- API：configure(Config) -> Result<Clocks, Error>（含 HSE/PLL 使能与锁定等待、Flash 等待周期自动升降、80MHz 穿越 HPRE 中间档、SW 切换轮询 SWS）；enable_ahb1/ahb2/apb1/apb2 + reset_* 总线助手（均含 LL 式读回/Force+Release）。
- 关键事实（出处已写入代码注释与 skill/hardware-flow.md）：SW/SWS 00=HSI/01=HSE/10=PLL；PLL 参数在 CFGR3（PLLSRC/PLLXTPRE/PREDIV/POSTDIV/FBDIV，倍频=FBDIV+2，×2..257）；HPRE_DIV1 编码=0x00；Flash WS 表无 2 档（75~100MHz→4WS）；HCLK≤170MHz、PCLK≤85MHz；CR 复位 0x0080_2083（HSI 默认开且就绪）；80MHz 穿越需 HPRE /2 中间档；HSE_STARTUP_TIMEOUT=100ms。
- 陷阱：Config 为 #[non_exhaustive]，外部只能 Default+字段赋值构造；HAL_RCC_GetSysClockFreq 的 HSE 值是编译期 HSE_VALUE（板级 24MHz），驱动改为运行时传入 HseConfig.hz。
- 编译验证：dev + release（thumbv7em-none-eabihf，cargo clean 后强制重建）零 error 零 warning。

## 按 STM32F412 例程对齐 embassy-stm32 API 形态（重构）
- 用户指出驱动风格未严格对齐 embassy-stm32（缺 embassy_stm32::init、GPIO 获取方式不同），并放入 参考设计/stm32f412rgt6-microboard 例程（init(enable100_mhz()) → Output::new(p.PC15,...)）。
- 全面重构 embassy-py32：
  - lib.rs：新增 `init(Config) -> Peripherals`、顶层 `Config { rcc }`（non_exhaustive + Default）、`Hertz(pub u32)`；Peri 改为 embassy 同款"携带单例值"（inner: T + Deref + const new_unchecked + T: Copy）。
  - peripherals.rs：单例 PA0…PF15 + `Peripherals` 结构体（字段 Peri<'static, PAx>，AtomicBool 防重复 take，#![allow(non_snake_case)]）。
  - gpio.rs：Flex/Input/Output/OutputOpenDrain 全部非泛型（内部 AnyPin 类型擦除，pin_port = 端口×16+引脚）；构造器签名照抄 embassy 0.6（OutputOpenDrain 拆 new/new_pull）；Pin trait 改 runtime accessor（SealedPin + Pin: PeripheralType + Into<AnyPin>）；Drop → set_as_disconnected；时钟使能复用 rcc::enable_ahb2（IOPxEN 从 bit2 起，mask = 1<<(2+port)）。
  - rcc.rs：公开 API 改 embassy 命名（hse/pll_src/pll/sys/ahb_pre/apb1_pre/apb2_pre；Hse{freq,mode,drive}/HseMode/PllSource{HSI(=HSI/2),HSE}/Pll{mul:u16,PllPreDiv,PllPostDiv}/Sysclk/AHBPrescaler/APBPrescaler）；rcc::init 写全局原子量，rcc::clocks() 查询；Clocks 字段 sys/hclk/apb1/apb2: Hertz。寄存器序列不变。
- demo main.rs 改为与 F412 例程同构写法；注意 use rcc::* 会遮蔽顶层 Config，需用模块路径。
- 经验：重写 lib.rs 两次漏 #![no_std]（报 can't find crate for std + concat!/derive 失效）；AnyPin 需补 PeripheralType + Copy 否则 Deref 约束级联失败。均写入 skill style-guide「工程结构对齐」一节。
- 编译验证：dev + release 零 error 零 warning。
