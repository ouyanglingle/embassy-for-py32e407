## 目标

在 `embassy-py32` 的 timer 模块新增 **QEI（正交编码器接口）同步驱动**：覆盖全部硬件支持编码器的实例 **TIM1/TIM2/TIM3/TIM4/TIM5/TIM8/TIM18**，配置面含模式/极性/输入滤波/输入预分频/ARR，API 提供 count/set_count/reset/max_count/read_direction/start/stop。仅同步、无 DMA/中断/Async。

## 关键一手依据（已核实）

- **哪些实例支持编码器**：RM 第 19 章（TIM1/8）与第 20 章（TIM2–5/18）有「编码器接口模式」；TIM9/12/15/16/17 的 `SMCR.SMS` 001/010/011 明确为**保留**，且 CMSIS `IS_TIM_ENCODER_INTERFACE_INSTANCE` 只列 TIM1/2/3/4/5/8/18。故只做这 7 个。
- **寄存器模型**：`SMCR.SMS`（RM 19.3.3/20.3.3）= `001` 编码器模式1（TI1，x2）、`010` 模式2（TI2，x2）、`011` 模式3（TI1+TI2，x4）。PY32 把 SMS 拆成 `SMS[2:0]`(bit2:0) + `SMS[3]`(bit16)，编码器四值只用低 3 位。`CCMR1` 输入视图：`CC1S/CC2S = 01`（IC 映射到 TI1/TI2）、`IC1F/IC2F`（4 位滤波）、`IC1PSC/IC2PSC`（2 位预分频）。`CCER.CC1E/CC2E` 使能、`CC1P/CC2P` 极性（`0` 上升/不反相、`1` 下降/反相；RM 明确编码器下不能配双边沿）。`CR1.DIR`(bit4) 在编码器模式下**只读**且反映旋转方向；`CNT` 即位置、`ARR` 即回绕边界。
- **HAL 流程**（`HAL_TIM_Encoder_Init` + `HAL_TIM_Encoder_Start`）：清 `SMCR.SMS|ECE` → 写 `CCMR1`(CCxS=01、ICxF、ICxPSC) → 写 `CCER`(CCxE=1、CCxP) → 写 `SMCR.SMS`；启动 = `CC1E/CC2E`(CCxE) → `CEN`，**不写 `BDTR.MOE`**（编码器输入无需主输出）。
- **PAC 字段名（已逐文件确认）**：`smcr.sms_l()`(3bit)/`sms_h()`(bit16)；`ccmr1_input()` 的 `cc1s/cc2s/ic1f/ic2f/ic1psc/ic2psc`；`ccer` 的 `cc1e/cc2e/cc1p/cc2p`；`cr1` 的 `cen/dir`；`cnt`/`arr` 用整寄存器 `bits()` 读写（tim1 CNT 16 位、tim2 CNT 31 位且 bit31=UIFCPY 需屏蔽）。
- **寄存器块仅两类**：TIM1/8 用 `pac::tim1`，TIM2/3/4/5/18 用 `pac::tim2`；两块的字段名完全一致，故可用同一宏实现编码器寄存器操作。实例计数器位宽不同 → `max_count` 放在实例 trait（TIM2=0x7FFF_FFFF，其余=0xFFFF）。
- **引脚复用**：编码器 TI1/TI2 输入即该定时器的 **CH1/CH2 引脚**，与 `timer::pwm` 已有的通道引脚 AF 表完全一致（如 TIM1 CH1=PA8/AF6、CH2=PA9/AF6，有官方例程 `TIM1_EncoderTI2AndTI1` 佐证；TIM2 CH1=PA0/AF1、CH2=PA1/AF1）。故**复用 `pwm::ChannelPin<T, Ch1/Ch2>`，不重复建表**。

## 新增/修改

### 1. `embassy-py32/src/timer/qei.rs`（新建，主交付）
模块 doc 列 HAL/LL/RM/DS 出处与上述事实。

**公开类型**
- `QeiMode { Mode1, Mode2, Mode3 }`（x2 TI1 / x2 TI2 / x4 TI12）→ SMS 1/2/3。
- `Polarity { Rising, Falling }` → `CCxP`。
- `Prescaler { Div1, Div2, Div4, Div8 }` → `ICxPSC` 0/1/2/3。
- `Direction { Up, Down }`（`CR1.DIR`）。
- `#[non_exhaustive] Config { mode, ch1_polarity, ch2_polarity, ch1_filter: u8, ch2_filter: u8, ch1_prescaler, ch2_prescaler, auto_reload: u32, ch1_pull: Pull, ch2_pull: Pull }` + `Default`（Mode3 / Rising / filter 0 / Div1 / ARR 0xFFFF / 无上下拉）。

**实例/块 trait**
- 密封 `sealed::SealedEncoderBlock`（`configure(mode, pol1, pol2, f1, f2, psc1, psc2)`、`set_cen`、`dir`、`count`、`set_count`、`set_arr`、`arr`），用宏 `impl_encoder_block!(tim1)` / `(tim2)` 各实现一份（两块字段同名）。
- 密封 `sealed::SealedEncoderInstance { block() -> &'static dyn SealedEncoderBlock; max_count() -> u32 }` + 公开 `EncoderInstance: super::Instance + super::pwm::PwmInstance`；宏 `impl_encoder_instance!(TIM1, Tim1, 0xFFFF)` … `TIM2 … 0x7FFF_FFFF` … `TIM18`。

**驱动**
```rust
pub struct Qei<'d, T: EncoderInstance> { _peri: Peri<'d,T>, _ch1: Flex<'d>, _ch2: Flex<'d> }
```
- `new(tim, ch1: Peri<impl pwm::ChannelPin<T, Ch1>>, ch2: Peri<impl pwm::ChannelPin<T, Ch2>>, config) -> Result<Self, Error>`：`tim.enable_clock(); unsafe { tim.reset() }`（复用 timer 模块的 RCC 逻辑）→ 校验 `filter≤15`、`auto_reload≤max_count` → 取 AF、`Flex::new` + `set_as_alternate(af, speed, pull, PushPull)` → 写 `CCMR1`(input) → `CCER` → `SMCR.SMS` → `ARR` → `CEN=1`。
- `count() -> u32`、`set_count(u32) -> Result<(),Error>`、`reset()`、`max_count() -> u32`、`read_direction() -> Direction`、`start()`、`stop()`。

### 2. `embassy-py32/src/timer/mod.rs`
加 `pub mod qei;` 与 `pub use qei::{Direction, EncoderInstance, Polarity, Prescaler, Qei, QeiMode};`（`qei::Config` 留在子模块避免与 `timer::Config` 撞名）。

### 3. `demo-py32/src/main.rs`
加 TIM2 QEI 示例：`Qei::new(p.TIM2, p.PA0, p.PA1, qei::Config::default())`（PA0=TI1/CH1、PA1=TI2/CH2，AF1；两脚当前空闲），模式 3，读一次 `count()` 与 `read_direction()` 并 `defmt::info!` 记录。

## 验证

1. `export PATH="/usr/bin:/bin:$PATH"`；`embassy-py32` 跑 `cargo check --all-targets`（host）、`cargo clippy --all-targets`（确认 `qei.rs` 零告警），`demo-py32` 跑 `cargo build --release`（thumbv7em-none-eabihf）；修到 0 error/0 新 warning。
2. 编译错误优先核对 PAC 真实字段名（`smcr.sms_l/sms_h`、`ccmr1_input`、`ccer`、`cr1.dir/cen`），不改 PAC。
3. 实例集合与 `max_count` 逐一对照 CMSIS `IS_TIM_ENCODER_INTERFACE_INSTANCE` 与 RM 19/20 章。

## 交付说明
新增 `qei.rs`、改 `timer/mod.rs` 与 demo 两处；每个寄存器写入标注 HAL/RM 出处；说明仅 7 个实例支持编码器、SMS 001/010/011 语义、DIR 只读、CNT 即位置、ARR 回绕、编码器启动不写 MOE、以及引脚复用 pwm 通道表（TIM1 有官方例程佐证，其余为 DS 表）。
