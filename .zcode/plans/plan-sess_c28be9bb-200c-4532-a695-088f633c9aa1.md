## 目标

为 `embassy-py32` 新增 **USART1/2/3**（RM 第 37 章，PAC `pac::usart1`）同步 Blocking 驱动 `usart.rs`，风格对齐已有的 `uart.rs`/`lpuart.rs`。仅做异步 TX/RX（`CR2.CLKEN=0`，不占 CK 脚），引脚覆盖 DS 中全部 AF7 的 TX/RX。

## 关键调研结论（已用 RM+SVD+PAC+HAL 交叉验证）

- **数据寄存器**：HAL/LL/RM/CMSIS 都只有偏移 **0x04** 的单个 `DR`（读=收、写=发）。PAC 里 `rdr@0x20` 是 SVD 生成缺陷（RM 第 37 章寄存器表止于 0x1C）。**驱动收发一律用 `regs.tdr()` (0x04)**，并在模块 doc 注明该差异来源。
- **时钟/复位位**：USART1 = `APB2ENR.USART1EN` bit14（复位 `APB2RSTR` bit14，走 `rcc::enable_apb2`/`reset_apb2`）；USART2 = `APB1ENR1` bit17、USART3 = bit18（走 `rcc::enable_apb1(mask,0)`/`reset_apb1`）。需按实例分总线。
- **初始化序列**（`HAL_USART_Init` → `USART_SetConfig`）：`UE=0` → `CR1`(M1/M0、PCE/PS、TE/RE) → `CR2`(STOP、CLKEN=0) → `CR3`(清 RTSE/CTSE、OVER8=0) → `BRR` → `CR2.LINEN=0`、`CR3.SCEN/HDSEL/IREN=0` → `UE=1`。HAL 对 USART 无 TEACK/REACK 等待，照做。
- **波特率**（`USART_BRR_SAMPLING16`，与 C 宏逐位一致）：`div100=PCLK*25/(4*baud)`，`mant=div100/100`，`fraq=(div100-mant*100)*16+50)/100`，`BRR=(mant<<4)+fraq`；拆分为 `DIV_M[11:0]`/`DIV_F[3:0]` 写入。`BRR` 需落在 16..=0xFFFF，否则 `InvalidConfig`。
- **外设时钟源**：`RCC_CCIPR.USART1SEL`(0:1)/`USART2SEL`(2:3)/`USART3SEL`(4:5)：00=PCLK（USART1 为 PCLK2，USART2/3 为 PCLK1）、01=SYSCLK、10=HSI、11=LSE（LSE 未实现 → `InvalidConfig`）。算波特率前按选择器取实际频率。
- **状态位**：`SR`：`PE`(0) `FE`(1) `NE`(2) `ORE`(3) `IDLE`(4) `RXNE_RXFNF`(5) `TC`(6) `TXE_TXFNF`(7)。发：等 `TXE_TXFNF` → 写 `TDR`，收尾等 `TC`。收：等 `RXNE_RXFNF` → **先读 `SR` 再读 `TDR`**（该序列同时清 RXNE 与 PE/FE/NE/ORE/IDLE，RM 37.4.1）。PAC 的 `SR` 无 PE/FE/NE/ORE/TC 写访问器，故不能用写 1 清零。
- **校验极性**：USART `PS=0` 为**偶**校验、`PS=1` 为奇（同 STM32/第 39 章 LPUART，与第 38 章 UART 相反）。

## 要新增/修改的文件

### 1. `embassy-py32/src/peripherals.rs`
- 增加 `periph!(USART1); periph!(USART2); periph!(USART3);`（附注释：RM 第 37 章，基址 0x4001_3800/0x4000_4400/0x4000_4800）。
- 在 `impl_peripherals!(...)` 列表加入 `USART1, USART2, USART3`，使 demo 可写 `p.USART1`。

### 2. `embassy-py32/src/lib.rs`
- 增加 `pub mod usart;`（保持模块字母序/就近放置）。

### 3. 新建 `embassy-py32/src/usart.rs`（核心）
结构完全对照 `lpuart.rs`，公开项 100% doc 注释、寄存器处标注出处：

- 模块 doc：目标外设、与第 38/39 章串口的区别、`DR@0x04 / rdr@0x20` 的 SVD 缺陷说明、AF7 说明、`new_blocking` 命名约定、仅同步。
- `const TIMEOUT_LOOPS: u32 = 1_000_000;`（与其它模块一致）。
- `pub enum Error { Parity, Framing, Noise, Overrun, Timeout, InvalidConfig }` + `Display` + `core::error::Error`。
- 配置枚举：`DataBits{7,8}`、`Parity{None,Even,Odd}`、`StopBits{STOP1,STOP0_5,STOP2,STOP1_5}`（CR2.STOP 四档）、`BitOrder{LsbFirst,MsbFirst}`，各带映射到 `CR1.M1/M0`、`(PCE,PS)`、`CR2.STOP` 的私有方法。
- `#[non_exhaustive] pub struct Config { baudrate, data_bits, stop_bits, parity, bit_order, swap_tx_rx, tx_pull, rx_pull, speed }` + `Default`（115200-8N1、RxUp、VeryHigh，对齐官方 STK 例程）。
- `enum Bus { Apb1, Apb2 }`；`mod sealed` 定义 `SealedInstance { regs()/bus()/enable_mask()/peripheral_clock()? }`、`SealedTxPin`/`SealedRxPin { af_num() }`。
- `impl_instance!` 生成三实例：`USART1`(Uart1?→`Usart1`, APB2, bit14)、`USART2`(Usart2, APB1, bit17)、`USART3`(Usart3, APB1, bit18)；`peripheral_clock()` 读 `CCIPR` 对应 `*SEL` 字段。
- `impl_tx_pin!`/`impl_rx_pin!` 全 AF7 引脚：
  - USART1 TX：PA9/PB6/PC4/PE0；RX：PA10/PB7/PC5/PE1
  - USART2 TX：PA2/PA14/PB3/PD5；RX：PA3/PA15/PB4/PD6
  - USART3 TX：PB9/PB10/PC10/PD8；RX：PB8/PB11/PC11/PD9/PE15
  - doc 注明：AF7 来自 DS 表 3-3…3-7（PDF 抽取会丢空单元格，已用引脚定义表+固件 `GPIO_AF7_USART*` 宏+已实现的 LPUART 引脚交叉校准）；PA14/PA15/PB3/PB4 属 SWJ 调试脚，用作 USART2 需板级取舍。
- 驱动类型 `Usart`/`UsartTx`/`UsartRx`，构造器 `new_blocking`、`Usart::new_blocking_with_tx/_rx`、`split()`、`dup_peri()`、`enable_and_reset::<T>()`（按 Bus 分派 APB2/APB1）。
- `init_regs::<T>()`：按上面 HAL 序列；`CR2` 只动 STOP（并清 CLKEN），`CR3` 清 OVER8/RTSE/CTSE/HDSEL/IREN/SCEN；`BRR` 按 `DIV_M`/`DIV_F` 写入。
- `UsartTx::write_byte/write/flush`（等 TXE 写 TDR；收尾等 TC）；`UsartRx::read_byte/read`（等 RXNE、序列读 SR+TDR、`take_line_error` 用读 SR 语义判定优先级 Overrun>Framing>Noise>Parity）。
- 私有 `baudrate_div()`、`wait_until()`、`peripheral_clock()`（实例级）。

### 4. `demo-py32/src/main.rs`
- 增加 USART1 最小示例：`Usart::new_blocking(p.USART1, p.PA9, p.PA10, cfg)` @115200，打印一行；主循环可选 echo 一字节。PA9/PA10 与现有 demo 外设无冲突。

## 验证

- `embassy-py32`：`cargo check --all-targets`（host，no_std 库可编译）。
- `demo-py32`：`cargo build`（`thumbv7em-none-eabihf`）。
- 目标零 error、零新增 warning；编译错误优先核对 PAC 真实字段名（本 SVD 无枚举值，多位数一律 `unsafe { w.f().bits(n) }`）。
